# HealthManager++ v0.1.15

## 就诊枢纽卡（spec 20 P1）

- 就诊记录页每条就诊可**展开枢纽卡**，一眼看到这次就医的完整上下文：
  - **就诊前后 7 天检验**：窗口内的检验批次（日期 + 项数 + 异常数），口径与趋势对比页完全一致；
  - **当时在用药**：起止日期覆盖就诊日的药品（剂量/频次一并展示；起止未填的按长期在用处理并标注）；
  - **相关病史**：就诊时点处于「患病中」的病史（在患 / 就诊时未愈）。
- 一次只展开一行，点行尾箭头展开/收起。

## 就诊前后疗效对比（spec 20 P2）

- 枢纽卡新增「**前后对比**」：自动定位就诊前最近一次与就诊后最近一次检验（**不限窗口取最近**，标注距就诊天数），逐指标展示**本次 / 上次 / 变化方向与幅度 / 异常状态**。
- 对比口径与趋势对比页**同一来源**（含单位换算与「单位不可比」降级），就诊后尚未复查时明确提示「就诊后暂无检验记录」。

## 体验修复（中文残留清理）

- 就诊记录页：页头与空态提示、删除按钮文案中文化。
- 首页复查提醒卡：「复查计划」链接、「X 天后 / 已逾期 X 天」「上次检查 X 天前」中文化。
- 复查计划页：分组标签（已逾期 / 即将到期 / 计划中 / 按计划）、卡片文案（今天复查、自定义复查间隔、暂停/恢复提醒、查看趋势、欠佳）全部中文化。
- 病史记录页中文化：页头、在患 / 已痊愈分组、空态、菜单（恢复为在患 / 删除）；严重程度徽标（轻度 / 中度 / 重度）。
- 「添加病史」弹窗字段中文化：病史名称 / 状态 / 严重程度 / 发病日期 / 痊愈日期 / 诊断医生 / 备注。
- 化验指标卡：「欠佳 · 区间」「N 次结果」中文化。

## 布局与显示修复（验收反馈）

- 就诊记录页行布局重排：摘要与病历小节改为「标签列 + 内容列」两列结构，内容限宽放宽（修复文字全部挤在左侧的问题）。
- 「前后对比」弹窗放宽至与对比表匹配的宽度（修复表格被窄弹窗裁切、信息显示不全的问题）。

## 技术说明

- 批次对比计算抽离为共享模块（趋势对比页与就诊枢纽卡同一口径，差分实证输出完全一致）。
- 本版**无数据库迁移**，零新表零新列，升级无风险。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
- AI 相关分析只发送到你**自己配置的 AI 渠道**，不经任何第三方中转。
