# HealthManager++ v0.1.3

## 面向用户的更新

- 新增家庭健康概览，可快速了解每位成员的报告、复查、用药、健康记录和基础资料状态。
- 家庭成员数据、复查计划和最佳范围设置均独立保存，不会相互混用。
- 登录页可在输入最近使用邮箱的首字母后快速预填邮箱；密码仍由 Windows 或浏览器密码管理器安全填写。
- 注册时会拒绝非法姓名字符、无效邮箱及控制字符。
- Windows 菜单首项 `Window` 现在提供“软件更新”和“关于 HealthManager++”。
- 客户安装包内置全部必需运行时：应用界面、文档解析服务、PostgreSQL 和数据库迁移。

## 安装与升级

1. 下载 `HealthManager++-Setup-0.1.3-x64.exe`。
2. 运行安装程序并完成安装。
3. 首次启动会自动初始化本地数据库；后续启动会自动应用必要的数据库迁移。

升级前无需导出数据。安装程序和应用均不会删除 `%APPDATA%\@openvitals\desktop\data` 内的本地健康数据。

## 隐私说明

此安装程序不包含任何开发者或其他用户的健康数据。数据在首次运行后仅保存在安装者自己的 Windows 用户目录中。
