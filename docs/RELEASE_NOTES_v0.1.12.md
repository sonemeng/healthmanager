# HealthManager++ v0.1.12

## 新功能

- **健康大屏（趋势对比页新视图）**：
  - 把关心的指标加为「关注」，一屏卡片墙总览：最新值大字、红绿灯状态、与上次相比的升降箭头与幅度、迷你趋势线。
  - 首次使用时根据最新一次检查**自动建议关注**异常与临界指标，一键保存；随时增删、按成员隔离。
  - 点卡片原地展开完整趋势图与最近两次对比，参考区间移入悬浮提示，画面干净。
- **AI 饮食建议（健康大屏 + 健康报告页双入口）**：
  - AI 结合该成员**最新一次检查的全部指标、在用药物、过敏史与病史**，对 126 种预置候选食物（7 大类，依据国家卫健委《成人高血压/高脂血症/糖尿病食养指南（2023 年版）》收录）逐项给出**推荐 / 适量 / 限制 / 避免**四档判定、具体食用量与关联指标说明。
  - **禁止事项**：药物-食物相互作用、疾病忌口、老人烹调注意事项，按该成员用药与指标挑选适用条目并给出针对性原因。
  - **存档可回看**：每次生成独立存档；清单可手动编辑（按忌口/口味/购买情况调整），生成原版保留可切换查看；支持导出 Markdown（含免责声明）。

## 数据库

- 新增两张表（应用启动时自动完成迁移，数据不受影响）：关注指标表、饮食清单存档表。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错：实测只设 `TEMP` 会少装约 1870 个文件，两个都设只少 187 个（都是超长路径的依赖文件，`@opentelemetry/api/build/esm/**`，不影响使用）。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
- AI 饮食建议生成时，会把你选择成员的检验指标、在用药物、过敏史与病史发送到**你自己配置的 AI 渠道**（与既有 AI 综合健康分析同一链路），不经任何第三方中转。
