# HealthManager++ v0.1.4

## 修复

- 恢复完整 Windows 顶部菜单：`File`、`Edit`、`View`、`Window` 和 `Help`。
- `Edit` 提供撤销、重做、剪切、复制、粘贴和全选。
- `View` 提供刷新、强制刷新、缩放和开发者工具。
- `Window` 保持将“软件更新”和“关于 HealthManager++”置于最上方。

## 安装与升级

下载 `HealthManager++-Setup-0.1.4-x64.exe` 并运行安装程序。升级不会删除 `%APPDATA%\@openvitals\desktop\data` 中的本地健康数据。

## 隐私

客户安装程序不包含任何开发者或其他用户的账号、健康记录、数据库或附件。
