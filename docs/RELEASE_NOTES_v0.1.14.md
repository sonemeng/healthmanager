# HealthManager++ v0.1.14

## 「我的关注」实测语义修复

- 修复「我的关注」把**本次未检查**的指标误显示为「正常」的问题：
  - 现在按批次倒序取**最近一次实测值**——本次未查的指标显示**无数据**或**未判定**，占位行（「消失」列）不再参与；
  - 徽标三态：**异常 / 正常 / 未判定 / 无数据**，与实际判定结果严格对应；
  - 实测不在最新一次检查时，副标题追加「**上次检查 日期**」；
  - 展开面板的趋势图、历次记录、参考区间全部改用实测行的单位与区间。

## 指标字典全量中国化（159 条）

- 全部指标按**中国标准**重查重立：卫健委 WS/T 系列（血细胞分析 405、肝酶 404.1、蛋白 404.2、电解质 404.3、胆红素 404.4、尿素/肌酐 404.5、钙磷镁铁 404.6、LDH/CK 404.7、CRP 404.9）、WS/T 428（BMI）、WS/T 645.2（肿瘤标志物）、WS/T 677（维生素 D）、《中国血脂管理指南（2023）》与国内化验单通行口径，每条来源可查。
- **美制 ARUP 参考区间整体替换**（87 行）：肌酐不再按 mg/dL 0.6~1.2，而是 **μmol/L 男 57~97 / 女 41~73**（20-59 岁，60 岁以上分列）——与你的化验单口径一致。
- 单位全面切换为中国习惯：血红蛋白 g/L、血糖 mmol/L、血脂 mmol/L、肌酐 μmol/L、体温 ℃、身高 cm、体重 kg 等。
- **单侧区间判定生效**：总胆红素（男 ≤26 μmol/L）、血脂（TC ≤5.2、TG ≤1.7、LDL ≤3.4 mmol/L）等「合适水平」单侧国标区间现在能真正判定异常/正常。
- 方法依赖项（甲状腺化学发光、肌钙蛋白、BNP 等）与月经周期分期激素（FSH/LH/E2/P）**不再硬编单一区间**：标注「以报告单为准」与分期表，避免错判。
- 尿糖/尿蛋白改定性口径（阴性）。

## 化验单区间学习入库

- **你确认过的报告原文参考区间现在会沉淀进字典**：确认/纠正观测时自动记录该检验科的区间（按指标+单位+区间去重），下一次导入无区间的报告也能正确判定。
- 学习行的来源标注：报告单带**检验结果互认标识**（如「陕HR」）的直接显示标识；无标识的显示「检验科区间」。
- 生物标志物库的参考区间按来源分组展示：**国家标准 / 指南口径 / 通行口径 / 检验结果互认（报告单标识）/ 检验科区间（报告单学习）**。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错：实测只设 `TEMP` 会少装约 1870 个文件，两个都设只少 187 个（都是超长路径的依赖文件，`@opentelemetry/api/build/esm/**`，不影响使用）。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。
- 升级后**首次启动**会自动应用字典迁移（0018/0019）：只改指标字典与学习行来源标注，**不会改动你已有的化验记录与异常标记**。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
- AI 相关分析只发送到你**自己配置的 AI 渠道**，不经任何第三方中转。
