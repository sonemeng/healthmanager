# HealthManager++ v0.1.8

## 修复

- **传错人的报告现在会提醒**。解析时会把报告上识别出的患者姓名与所选成员档案的姓名比对；不一致时任务会进入「待复核」队列并写明双方姓名（如「报告患者姓名（吴桂英）与档案姓名（吴菊兰）不一致」）。数据照常入库不阻断——确认传错后可在上传页删除该单，换正确档案重传。
- **修复「删除导入任务」必然失败的问题**。以前对已解析出数据的任务点删除会报错（数据库外键无级联）；现在删除任务会在同一事务里连带清掉它产生的全部观测数据，一次删净。
- **化验项目匹配重写为评分制**。`丙氨酸氨基转移酶(陕HR)`（地区互认后缀）、`*天门冬氨酸氨基转移酶`（星号异常标记）、`C-反应蛋白`（连字符）这类写法以前会整批匹配失败（实测一批报告 39% 的项目落不进字典），现在通过名称清洗 + 四层评分（精确 id → 精确名 → 别名 → 双向包含 + 排除表）正确命中。
- **参考区间对应性门禁**：观测单位/数值量级与字典区间对不上时，宁可区间留空，也不给出错误的「偏高/偏低」判断。
- **字典新增血小板三项**：PCT（血小板压积）、P-LCR（大血小板比率）、P-LCC（大血小板数目），种子数据全量同步（现共 144 个指标）。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错：实测只设 `TEMP` 会少装约 1870 个文件，两个都设只少 187 个（都是超长路径的依赖文件，`@opentelemetry/api/build/esm/**`，不影响使用）。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
