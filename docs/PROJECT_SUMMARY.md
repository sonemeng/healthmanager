# HealthManager++ 项目总结

## 产品定位

HealthManager++ 是一套本地优先的家庭健康档案桌面应用。它在用户电脑上运行 Web 界面、后台解析服务和 PostgreSQL 数据库，不依赖托管数据库保存日常健康记录。

## 已完成能力

- 家庭成员档案、成员切换及全站数据隔离。
- 报告上传、解析、指标标准化与来源追溯。
- 指标趋势、用药、病史、就诊记录和健康时间线。
- 家庭健康概览：最近报告、待复查、在用药、健康记录总数与基础资料完整度。
- 成员级复查计划和最佳范围配置，按 `user_id + profile_id + metric_code` 约束隔离。
- 个人健康报告导出和最小化数据共享能力。
- Windows 桌面运行时：内置 Next.js、解析 Worker、PostgreSQL 和数据库迁移。
- 登录快捷预填：仅保存最近使用的邮箱，不保存明文密码；密码交由系统密码管理器处理。
- 注册前端与服务端双重输入校验。

## 数据与安全边界

- 客户发行包不预置任何账号、健康记录、数据库或附件。
- 用户数据位于 `%APPDATA%\@openvitals\desktop\data`。
- 软件升级不会主动清理该目录。
- 个人数据备份仅生成在本机 `apps/desktop/release-personal`，已被 Git 忽略，禁止上传或分发。
- 本地账户密码由 Better Auth 处理，应用不会自行保存明文密码。

## 发布验证

- 数据库和 Web TypeScript 类型检查。
- Next.js 生产构建。
- Electron 主进程构建。
- 桌面运行时重建。
- 本地数据库迁移和外键/唯一约束核验。
