# HealthManager++ v0.1.17

## 按病史聚合病程时间线（spec 20 P5）

- 病史记录页每条病史可**展开**，查看该病史的「关注指标」清单（含每项已有观测次数）与病程入口：
  - **慢性肾功能不全**：肌酐、尿素氮（BUN）、尿酸、胱抑素C、eGFR、白蛋白/肌酐比值、尿微量白蛋白、尿肌酐（8 项）
  - **2 型糖尿病**：空腹血糖、糖化血红蛋白（HbA1c）、果糖胺（3 项）
  - **脑梗死**：总胆固醇、甘油三酯、LDL-C、HDL-C、非HDL-C、VLDL-C（血脂 6 项）
  - 高血压暂不映射（检验单通常不含血压项，不硬造映射），展开后显示说明。
- **病程时间线**：关注指标合计观测满 **3 次**后，展开区出现「病程时间线」按钮，进入 `/timeline?condition={id}` 聚合视图——
  - 检验泳道与关注指标曲线只渲染该病史的映射指标；就诊、病史事件点与用药泳道保留完整上下文；
  - 头部「该病史关注指标」聚合卡展示全部映射指标与各自积累次数（未检测的标「待检测」）；
  - 泳道 / 列表两种视图均可用，点击事件可看详情。
- **数据积累中门槛**：观测不足 3 次时入口显示「数据积累中（还需 N 次）」；直接访问 URL 同样拦截并给出说明，不渲染半成品视图。
- 映射字典按 2026-10-13 逐条确认定稿，全部 code 已对指标字典（144 项）核实存在。

## 数据修复

- 修复病史重复问题：删除 10-09 导入时产生的 3 条重复旧病史（2 型糖尿病 / 高血压 / 慢性肾功能不全 各 1 条空备注旧行），保留带 ICD 编码的完整条目，每种病史各剩 1 条。

## 技术说明

- 病史-指标映射为常量字典（`condition-metric-map.ts`），无数据库迁移、无新表；入口门槛数据由新增 `conditions.timelineGate` 查询聚合（口径与时间线页一致）。
- 时间线病程模式完全复用既有泳道派生层（`derive.ts`），普通时间线行为零变化。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
- AI 相关分析只发送到你**自己配置的 AI 渠道**，不经任何第三方中转。
