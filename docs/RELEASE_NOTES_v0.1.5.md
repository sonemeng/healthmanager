# HealthManager++ v0.1.5

## 修复

- 修复 0.1.4 安装程序在部分机器上启动即闪退的问题（崩溃模块 `nsis7z.dll`，异常码 `0xC0000005`）：安装载荷中混入了 ARM64 原生二进制文件，安装器内置的解压组件无法处理其压缩方式。
- 安装载荷不再包含非 Windows x64 平台的二进制文件，安装包体积由 528.62 MB 降至 235.01 MB。
- 安装包产物名统一为 `HealthManager++-Setup-<version>-x64.exe`。

## 安装与升级

下载 `HealthManager++-Setup-0.1.5-x64.exe` 并运行安装程序。升级不会删除 `%APPDATA%\@openvitals\desktop\data` 中的本地健康数据。

若安装后疑似缺少文件，请在安装前把临时目录指向短路径再重装，例如 `set TEMP=D:\t`：Windows 会静默跳过解压路径超过 260 字符的文件。

## 隐私

客户安装程序不包含任何开发者或其他用户的账号、健康记录、数据库或附件。
