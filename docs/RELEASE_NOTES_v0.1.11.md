# HealthManager++ v0.1.11

## 新功能

- **趋势对比页（新导航页）**：同一天视为一次检查，每次检查自动与紧邻的上一次全量对比。
  - 每项指标显示本次值、上次值、变化幅度与方向箭头（**↑ 红色升高 / ↓ 绿色降低**，仅示方向、不代表好坏）。
  - 本次新出现的指标标「新增」，上次有本次没有的标「消失」；不同批次的同一指标单位不一致时，自动按换算表换算到基准单位再比，无换算规则的显示「单位不可比」。
  - 双视图：**批次对比**（按检查日期倒序分区块，默认展开最新一次，显示与上次的间隔天数）和**历年总表**（行 = 指标，列 = 每次检查日期，可横向滚动）；只有一次检查时隐藏总表。
  - 对比口径与趋势页一致：未匹配项与待人工匹配项不参与对比；同一指标同一天多条时取最新确认的一条。
- **就诊记录可回看原始病历**：就诊卡片的操作菜单新增「查看原始病历」，一键跳转到该次上传的详情页（原图对照 + AI 识别全文）；手动新建、无上传来源的就诊记录不显示该入口。

## 修复

- **报告原图查看器滚轮穿透**：在原图上滚动滚轮缩放时，页面不再跟着一起滚动（根因：React 合成滚轮事件是 passive 监听，无法拦截默认滚动行为；已改为原生非 passive 监听）。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错：实测只设 `TEMP` 会少装约 1870 个文件，两个都设只少 187 个（都是超长路径的依赖文件，`@opentelemetry/api/build/esm/**`，不影响使用）。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
