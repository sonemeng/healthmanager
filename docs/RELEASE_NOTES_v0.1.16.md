# HealthManager++ v0.1.16

## AI 就诊摘要（spec 20 P3）

- 就诊记录页枢纽卡新增「**AI 摘要**」按钮：为单次就诊生成一份交给接诊医生看的中文摘要（Markdown），快速掌握「为什么来、查了什么、当时状态、在用什么药」。
- 摘要五节结构：**主诉与现病史 / 近期检验要点（±7 天批次异常项）/ 当前用药 / 既往病史 / 上次就诊后变化**，每条结论引用指标名 + 数值 + 日期，无数据的节明确说明、不编造。
- 手动点击生成（不自动预生成，省 AI 调用）；支持**重新生成**（保留历史）与**导出 .md**；未配置 AI 渠道时明确提示先去设置中配置。
- 与综合健康报告互补：一个管「历年综合」，一个管「单次就诊」。

## 医嘱复查提醒（spec 20 P4）

- **自动解析**：就诊记录（含上传确认的候选就诊）保存时，自动从医嘱建议中解析「三个月后复查」「两周后复诊」「半年复查」等明确期限，生成带日期的复查提醒。
  - 解析口径：月 = 30 天、年 = 365 天、半年 = 180 天；多处匹配**取最晚**（宁晚勿早）；「定期复查」「择期复查」等无明确期限的**不自动生成**（禁止猜周期）。
  - 提醒行展示医嘱原文摘录，可核对来源；多处匹配时标注「共 N 条医嘱匹配，取最晚」。
- **手动补录**：无明确期限的医嘱（如「不适随诊」）可在枢纽卡「复查提醒」节手动补录日期与备注。
- **提醒管理**：每条提醒可标记「已完成」或「不再提醒」；重新保存就诊会自动刷新解析结果（手动补录行与已处理的行不受影响）。
- **首页合并**：医嘱来源的提醒与按指标周期推算的复查计划在首页「复查提醒」卡合并展示，医嘱行标注「医嘱：{原文}」，按到期先后排序。

## 技术说明

- 新增数据库迁移 **0020_follow_up_reminders**（新表 `follow_up_reminders`，幂等 CREATE IF NOT EXISTS，已在生产库克隆库预演两遍通过）；升级自动执行，不影响既有数据。
- 复查时间解析器为纯函数（15 用例探针全过），挂载于就诊创建/编辑与上传候选确认三处，失败不阻断主流程。
- AI 摘要与枢纽卡/前后对比共用同一套数据口径（单一来源，不另造第二套）。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
- AI 相关分析只发送到你**自己配置的 AI 渠道**，不经任何第三方中转。
