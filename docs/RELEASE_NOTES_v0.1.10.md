# HealthManager++ v0.1.10

## 新功能

- **用药记录支持编辑**：每张用药卡片新增「编辑」，可修改名称、用量、频次、给药途径、开方医生、用途、开始日期与备注——此前导入的药物只能删除重建。
- **用药状态管理**：在用 ↔ 已停用一键切换，停用自动记录停用日期；卡片显示完整起止时间。
- **用药变化分段记录（用药历史）**：编辑时若用量或频次有变化，可选择「仅修正本记录」（原来录错了）或「记录为新阶段」——后者会自动把旧记录停用至变更日、新开一条，形成可回顾的用药时间线，复诊时可直接回答「这药吃了多久、什么时候加量」。
- **模块导入不再丢弃其他记录**：从「添加药物」等模块入口导入门诊病历时，文档里的**病史、就诊记录**候选不再被过滤掉，可在确认页一并写入或忽略——此前同一份病历需要在三个模块各导一遍。
- **门诊病历结构化提取**：上传门诊病历（encounter note）时按原文分节提取**主诉、现病史、既往史、体格检查、医嘱建议**（此前全部被压缩成一段 AI 概括），确认后就诊详情页分节展示，导出文档同步包含。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错：实测只设 `TEMP` 会少装约 1870 个文件，两个都设只少 187 个（都是超长路径的依赖文件，`@opentelemetry/api/build/esm/**`，不影响使用）。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
