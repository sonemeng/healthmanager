# HealthManager++ v0.1.13

## 新功能

- **时间线（LifeLines 泳道式）**：原先按月的列表升级为一张四泳道时间轴，一屏看清「就诊 / 用药 / 病史 / 检查」四条线：
  - **就诊、病史、检查**画点：检查按天聚成一次检查（与趋势对比同口径），异常批次红点加粗；病史区分「确诊」实心点与「已痊愈」空心点。
  - **用药**画线段：同一药物换方案自动分段（0.1.10 起的分段历史）逐段成线，在用实色、已停用灰色。
  - **点任意点位 / 线段**弹出详情卡：就诊内容、用药分段区间与剂量、检验批次要点，并可一键「进入批次对比」或「基于此记录问 AI」。
  - 原按月列表保留为页内「列表」切换，信息不丢。
- **关注指标趋势（与泳道共用同一条时间轴）**：
  - 从「我的关注」里选 1–2 项叠在泳道上方，异常点红色加粗描边，色带即参考区间。
  - **「按年 / 按月」粒度按钮**切换横轴刻度；**底部拖动两端的把手**即可缩小时间范围，泳道与下方小图同步跟随。
- **关注指标同屏（分面小图矩阵）**：每个关注指标一张小图，纵轴各自独立（不合并量纲）、横轴与泳道共用刻度；点任意小图放大看完整趋势与逐次数值；检查不足 2 次的指标给出提示文案。

## 变化幅度 Top-N

- 「趋势对比 → 检查对比」顶部新增**变化幅度**条形图：最新一次 vs 上一次，按**生物指标分类**（15 类）分组，每类取 |Δ%| 前 10。**红=升高、绿=降低**（仅示方向，不代表好坏）；单位不可比的指标不参与排序。

## 中文化

- 时间线页的英文残留一并清理（原来的 `Timeline` / `Lab Results` / `Started …` 等英文标题、就诊类型英文名全部改为中文）。

## 安装与升级

- 安装前**必须同时**把 `TMP` 和 `TEMP` 指向短路径再装（NSIS 的 `GetTempPath()` **优先读 `TMP`**）：`set TMP=D:\t && set TEMP=D:\t`。Windows 会**静默跳过**解压路径超过 260 字符的文件，全程不报错：实测只设 `TEMP` 会少装约 1870 个文件，两个都设只少 187 个（都是超长路径的依赖文件，`@opentelemetry/api/build/esm/**`，不影响使用）。
- 覆盖安装到原目录即可；`%APPDATA%\@openvitals\desktop\data` 里的数据不会被动。

## 隐私

- 本安装包**不含任何个人数据**；你的数据始终只在本机 `%APPDATA%\@openvitals\desktop\data`（含内嵌 PostgreSQL）。
- AI 相关分析只发送到你**自己配置的 AI 渠道**，不经任何第三方中转。
